# CDL Reference Analysis

Reviewed 2026-11-05. Roadmaster Drivers School is used **only** as a reference for CDL topics and site features. Nothing below is an IMAN offering, and no Roadmaster text, branding or assets were copied into the IMAN site.

Labels used: **[RM]** = stated on Roadmaster's site · **[REG]** = federal/Florida regulation (verified against an official source where noted) · **[—]** = not found on the reference.

- Followed: https://www.roadmaster.com/cdl-training/, https://www.roadmaster.com/class-a-cdl-requirements/

## Verified regulatory facts used on the IMAN site

| Fact | Source |
|---|---|
| Florida CDL minimum age 18; under 21 restricted to intrastate | FLHSMV CDL page |
| 21 for interstate and for hazmat endorsement | FLHSMV CDL Handbook; 49 CFR 391.11(b)(1) |
| Florida residency documents required for original CDL/CLP | FLHSMV CDL page |
| Class A knowledge tests: General Knowledge, Combination Vehicles, Air Brakes (if applicable), endorsements | FLHSMV CDL page |
| Skills test: pre-trip inspection, basic vehicle control, on-road test; conducted in English | FLHSMV CDL page |
| CLP must be held 14 days before the skills test | 49 CFR 383.25(e) |
| ELDT required since 2022-02-07 for first Class A/B, B→A upgrade, P/S/H endorsements; provider must be on the TPR; theory score ≥ 80%; BTW is proficiency-based with no federal minimum hours; provider reports completion | 49 CFR 380 Subpart F; TPR site confirms Theory + BTW per class and provider reporting |
| DOT physical from an examiner on FMCSA's National Registry | 49 CFR 391.41–391.43; FLHSMV CDL Medical page |
| English proficiency for CMV drivers | 49 CFR 391.11(b)(2) (already cited on IMAN's assessment page) |
